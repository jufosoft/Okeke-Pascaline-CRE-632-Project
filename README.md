# CodeLearn Academy

Free static educational website for **Web Design and Development Fundamentals**. Built with HTML, CSS and JavaScript. No WordPress, paid hosting or build tools required.

## Course modules
1. Computer and Internet Fundamentals
2. HTML: Building Web Pages
3. CSS: Styling Your Website
4. Responsive Web Design
5. JavaScript Fundamentals
6. Forms and Website Accessibility
7. Website Publishing with GitHub Pages
8. Final Project: Personal Portfolio Website

## Run locally
Extract the ZIP and open `index.html` in Chrome, Edge or Firefox. For best results, run `python -m http.server 8000` in this folder and visit `http://localhost:8000`.

## Included
- Homepage, course catalogue and individual working lesson pages (`lesson.html?id=1` to `8`)
- Responsive CSS design
- Interactive quiz with automatic scoring and feedback
- Browser-local discussion forum
- Progress tracking and certificate printing
- Original local SVG illustrations
- Local placeholder videos and WAV audio files
- Browser text-to-speech narration on lessons

## Notes
Progress and discussion posts are stored in Local Storage on the current browser/device, not shared across students. Replace placeholder videos with your own recordings or licensed material. For a shared online forum, connect GitHub Discussions or Giscus. Update the contact email in `js/contact.js`.

## Free hosting
Upload the contents of this folder to a GitHub repository, then enable GitHub Pages in Settings → Pages. You can also deploy the extracted folder using Netlify or Cloudflare Pages.
